# Badger Supports website

Source for the public Badger Supports website: static pages built from versioned content,
native forms, and an API.

| Start with | For |
|---|---|
| [Development commands](docs/README.md#commands) | Requirements, local setup, build and check commands |
| [Architecture](docs/ARCHITECTURE.md) | Rendering, the API, storage and runtime configuration |
| [Extending the site](docs/EXTENDING.md) | Adding pages and block types |
| [Design](docs/DESIGN.md) | Styles, fonts, photos and motion |

The [development guide](docs/README.md) explains the prototype build and the checks.
A local checkout or passing check does not establish what is currently published.

This repository is public. Keep credentials, form responses and private student information
out of its files. Local prototype fixtures use fictional people and submissions.
