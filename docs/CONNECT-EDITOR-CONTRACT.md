# Connect editor contract

Generated by `node ops/contract.mjs` from the code the build enforces. Do not edit by hand: `node ops/check.mjs`
fails when this file and the code disagree. The Exchange request `PUBLIC-SITE-EDITOR-2026-10-20` asks Connect
for an editor that offers everything below; until it exists, the same records are edited as files in `content/`.

Every edit is published as a new version. The build checks a version before anything is published and refuses
it with the reasons listed, so an editor can show the same reasons before a director presses Publish.

## Pages (`bss.page/1`, `content/pages/`)

## Icons

Wherever a field takes an icon, it is one of these, each with its own small move when its link is pointed at or
pressed: `arrow`, `back`, `down`, `out`, `pin`, `mail`, `calendar`, `chat`, `scissors`, `bulb`, `badge`, `question`, `plus`, `star`, `check`, `play`, `pause`, `jar`, `pencil`, `ribbon`, `hand`, `hand-cream`. The build refuses any other name.

## Photos

Every photo slot — a block's photos, a hero circle, a room, a direction step, an event — takes one of three things:

| Form | Example | What happens |
|---|---|---|
| a library id | `"m-people-welcome"` | the photo in `media/manifest.json`, with its own description and focal point |
| a link | `"https://…/photo.jpg"` | the build fetches the photo once and serves it from this site, never from the link |
| a link with details | `{ "link": "https://…", "alt": "…", "focal": [50, 30] }` | the same, with a description and the point (percent across, percent down) to keep in view when it is cropped |

A link must start with `https://`. A Google Drive file link works when the file is shared as *Anyone with the link*;
a Drive folder link is refused. The build refuses a link that does not answer with a photo, and names it. A linked
photo with no description is read aloud as the text key `media.linkAlt`.

## Rooms and directions (`bss.place/1`, `content/places/`)

Adding a room is adding a record. A published room gets its own page at `/directions/<id>/`, appears on
`/directions/`, and every event held there links to it. A draft (`published: false`) gets no page and no link.

| Field | What it holds |
|---|---|
| `id` | permanent; a–z, 0–9 and single hyphens; also the page address |
| `published` | on: the room has a page and events link to it |
| `name` | **required** — the room, as its page's heading |
| `short` | how event lists name it (defaults to name) |
| `building, where` | the building, and the floor or room number |
| `address` | **required to publish** — the street address; the map button opens it |
| `links` | extra links, such as the building's hours |
| `photo` | an optional photo of the room (a library photo or a pasted link) |
| `steps` | optional — each has a permanent `s-…` id, its text, and an optional photo (a library photo or a pasted link); a room with none shows its address and map button only |
| `arrivePhoto` | an optional photo under the last line of the steps, of what a visitor sees on arriving |
| `note` | one closing line |
| `aliases` | old addresses that should 301 to this room's page |

## Team (Connect's public profiles, `bss.team-fixture/1`)

The team is not edited here. Each member writes their own profile in their Connect account and chooses whether it
is public; Connect exports the public ones and the build gives each a card on `/about/our-team/` and a page of its own
at `/about/our-team/<slug>/`. A page only says which groups the Team block shows, in what order, and what to call them.
A profile that is not public gets no card and no page. The old addresses under each group 301 to the team page.

| Field | What it holds |
|---|---|
| `id` | Connect's opaque id for the profile; never shown |
| `slug` | permanent; a–z, 0–9 and single hyphens; the page address |
| `published` | on: the member chose a public profile |
| `name` | **required** — as the member wants it shown |
| `pronouns` | optional |
| `classYear, credentials` | optional; a student's class year, or an advisor's credentials |
| `title` | **required** — the full title, on the card and the page |
| `role` | **required** — Connect's role word |
| `group` | **required** — one of `directors`, `associate-directors`, `staff`, `volunteers`, `advisors` |
| `order` | the order within the group |
| `bio` | paragraphs the member wrote |
| `photo` | a photo the member uploaded to Connect; with none, the card shows their initials |
| `contact` | only if the member chose to publish one: a badgersupports.org address |
| `aliases` | the member's old address on this site, to 301 to the new one |
